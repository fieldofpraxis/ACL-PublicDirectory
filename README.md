# AI Creator Labs - Learning Portal

Landing page portal belajar AI: Home, Resources (Skills), Knowledges (video library), dan Articles.

## Menjalankan

Satu file mandiri (`index.html`): CSS, JS, dan gambar sudah di-embed. Buka langsung di browser, atau deploy ke hosting statis apa pun (GitHub Pages, Netlify, Vercel).

## Catatan

- Navigasi memakai hash routing (`#resources`, `#knowledges`, `#articles`).
- Responsif untuk desktop dan HP.
- Masih placeholder: link video (satu URL YouTube), daftar dan URL skills, gambar artikel, testimoni, FAQ, dan statistik.
