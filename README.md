# AI Creator Labs - Learning Portal

Landing page portal belajar AI: Home, Resources (Skills), Knowledges (video library), dan Articles.

## Menjalankan

`index.html` (CSS dan JS inline) plus folder `images/` untuk semua gambar. Buka `index.html` langsung di browser, atau deploy folder ini ke hosting statis apa pun (GitHub Pages, Netlify, Vercel). Jaga `index.html` dan `images/` tetap sejajar.

## Gambar

Semua gambar ada di `images/`; ganti file di situ (nama sama) untuk mengubah tampilannya:

- `video-thumb-1..11.webp`: thumbnail video
- `article-man.webp`, `article-hands.webp`: foto placeholder artikel (selang-seling)
- `cta-bg.webp`: foto di blok "Mau belajar apa hari ini?"
- `logo-navbar.webp`, `logo-sidebar.webp`: logo
- `menu-resources.webp`, `menu-knowledges.webp`, `menu-articles.webp`: gambar di dropdown menu

## Catatan

- Navigasi memakai hash routing (`#resources`, `#knowledges`, `#articles`).
- Responsif untuk desktop dan HP.
- Masih placeholder: link video (satu URL YouTube), daftar dan URL skills, gambar artikel, testimoni, FAQ, dan statistik.
